# Confidential Mission v1.2.12 — Quest & PC VR

Game zoom now follows the arcade camera. Tap and release either grip, or choose Game zoom in the VR menu. It starts Off each launch, with a one-second purple message after toggling. World zoom keeps the HUD and held guns at their usual size. Both How to Play grip lines point to the squeeze buttons; these zoom/help changes were confirmed on Quest.

Reticle mode, minimum/maximum size and shrink distance, Wider-view HUD size, and Reset to defaults are included. Fresh or reset settings use the captured profile:

- In-game pistol, angle0, Shoot off-screen reload, P1 left/P2 right and LaserOn.
- Custom reticle:20% minimum,45% maximum,6.5m shrink distance.
- Medium haptics, world size0.110, panel distance40game units, HUD100% and Wider viewOn.

Valid existing choices remain saved. Reset to defaults applies the preset. Game zoom stays session-only; it is not saved. HUD size affects supported Wider gameplay UI, with Original/Service views retaining their normal size.

The Quest update preserves app data. PCVR and complete source are included; PCVR runtime testing remains separate from the accepted Quest zoom/help test. Bring your own Confidential Mission MAME set and NAOMI BIOS. No game is included.
