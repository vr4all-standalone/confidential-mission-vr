# Confidential Mission v1.3.4 — Quest & PC VR

**World size update:** your previous saved World size is replaced with **0.10 once**
on first launch after this update, including custom values. You can adjust it again
afterward; later choices persist. Other preferences and native game data are kept.

Gun extraction is required before first play and cannot be skipped. It creates the
native gun from your own game files; valid complete cached guns are reused. Missing,
damaged or incomplete caches trigger preparation. If extraction cannot finish,
setup explains how to recover rather than starting without the required gun.

- New **Gun / World / System / In-game** settings tabs, direct gun-model buttons,
  explicit P1/P2 layouts and confirmation for Reset/Quit.
- **Crosshair** naming throughout the UI and help. Laser choices: Off, Normal,2x,
  5x,10x. Right thumbstick click toggles laser and crosshair together, preserving
  dimensions. One trigger-selected pointer and a visible contact point operate menus.
- Wider view offers Off,On,Fade. Numeric World/Crosshair tuning is in Advanced.
- First Start on either controller chooses solo P1's hand; a fresh other-hand
  trigger transfers it. Unused-hand Start joins the missing native player, then
  the saved two-player layout applies. Controller help uses Start/Fire labels.
- Game zoom starts Off. Native enemy ring/X overlays follow zoom; cinematic bars
  pause it temporarily and requested On returns afterward. Choosing Off keeps it Off.
- In-game options: Game/Boss/Shifting difficulty and Collision size1–8, Life3–8.
  Stage changes, then **Apply settings and restart** saves through original Service
  and verifies the restarted game. That original save may turn off expired internet
  ranking; other untouched cabinet/calibration settings stay protected. Unsupported
  native revisions/unsafe states offer manual Service.

The Quest APK preserves package/signing identity and app data. App name remains
**Confidential Mission - VR4ALL**. Quest/PCVR/complete source and SHA256SUMS are
included. The earlier menu/zoom/shortcut changes were accepted on Quest; the new
migration/required preparation have separate software/simulator evidence. PCVR
headset play and new user physical acceptance remain separate checks.

Bring your own Confidential Mission MAME set and NAOMI BIOS. No game is included.
