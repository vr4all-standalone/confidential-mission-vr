# Confidential Mission 1.3.2 — local candidate

Right thumbstick click now toggles the laser and custom reticle together. If
either is visible, the next fresh click hides both; the following click enables
both. Holding the stick does not repeat the shortcut. The paired choice saves
once and survives restart. Laser thickness and reticle size/distance are kept.
Controller help says Laser/reticle. Existing menu pointers and individual menu
choices remain available, as do zoom, controls and native operator settings.

The user physically accepted 1.3.1 before requesting this small follow-up.
Package ID, signing identity and Confidential Mission - VR4ALL label are kept.
No game media is included. Builds/software checks, installation and physical
acceptance are separate; GitHub publication requires the user's approval.
