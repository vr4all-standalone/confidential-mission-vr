# Confidential Mission1.2.10 — Game zoom

- Tap and release either grip during gameplay to toggle Game zoom, or use Game zoom before How to play in the settings menu.
- Zoom starts Off each launch; Reset to defaults also turns it Off. It is not saved in emu.cfg.
- A purple Zoom enabled / Zoom disabled notice lasts one second. Startup and manual controller help label both grips, with inward leaders to the grip button.
- Zoom follows Confidential Mission's native animated camera. Only world XY changes; native HUD, held guns, head tracking, eye separation and scene depth keep their existing behavior.
- Grip+stick resizing, stick/pad clicks and slide reload consume the gesture. Focus/menu/Service/tracking interruptions and hand/player transitions require a fresh tap.
- Existing saved preferences, native gameplay, audio and source changes are preserved.

Quest and PCVR software/build checks are separate from physical play. This is an unpublished local candidate pending headset acceptance.
